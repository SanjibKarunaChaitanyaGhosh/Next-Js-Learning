## 📚 Tutorial Checklist

### 🟢 Phase 1: Getting Started with Next.js

- [ ] Install Next.js and create your first application
- [ ] Understand the App Folder Structure and `layout.js`
- [ ] Learn the Next.js App Router
- [ ] Build a Navbar using the Next.js `Link` component
- [ ] Understand Route Groups and Multiple Layouts
- [ ] Hide the Navbar on Specific Pages using Conditional Layouts

### 🎨 Phase 2: Styling and UI Components

- [ ] Install Tailwind CSS in Next.js
- [ ] Understand Global CSS vs CSS Modules
- [ ] Learn the Next.js Image Component
- [ ] Use the Next.js Font Component
- [ ] Add Multiple Fonts and Configure Typography
- [ ] Implement Metadata, SEO, Favicons, and Social Media Cards

### 🧭 Phase 3: Advanced Routing and URL Handling

- [ ] Understand Dynamic Route Segments
- [ ] Learn Dynamic Routing in Client Components
- [ ] Understand URL Search Parameters with `searchParams`
- [ ] Use `useSearchParams` in Client Components
- [ ] Learn Catch-All and Nested Dynamic Routes
- [ ] Handle 404 Errors with `not-found.js`
- [ ] Generate Static Pages using `generateStaticParams`

### ⚡ Phase 4: Rendering, Components, and Data Fetching

- [ ] Understand React Server Components vs Client Components
- [ ] Fetch API Data in Server Components
- [ ] Fetch API Data in Client Components
- [ ] Create a Random Joke Generator App
- [ ] Understand Suspense and Lazy Loading
- [ ] Implement Loading UI using `loading.js`
- [ ] Understand Static vs Dynamic Rendering
- [ ] Learn Incremental Static Regeneration (ISR)
- [ ] Understand React Cache and `cache()`

### 🗄️ Phase 5: Database and Full-Stack Development

- [ ] Connect Next.js with MySQL
- [ ] Fetch Live Data using Route Handlers / API Routes
- [ ] Build Dynamic Pages with MySQL Data
- [ ] Understand Server Actions
- [ ] Insert Form Data into MySQL using Server Actions
- [ ] Handle Client-Side Form Submission
- [ ] Use React's `useActionState` Hook
- [ ] Use `useFormStatus` to Display Loading States
- [ ] Understand Server Redirects with `redirect()`
- [ ] Implement Client-Side Navigation with `useRouter`
- [ ] Implement Back Navigation using `router.back()`

### 🔄 Phase 6: Server Actions and Data Revalidation

- [ ] Handle Server Actions with `useTransition`
- [ ] Understand `revalidatePath()`
- [ ] Implement Client-Side Data Revalidation
- [ ] Compare `router.refresh()` and `revalidatePath()`
- [ ] Understand On-Demand Revalidation
- [ ] Compare Revalidation, ISR, and Static Pages

### ✨ Phase 7: Animations and UI Libraries

- [ ] Learn Framer Motion / Motion for React
- [ ] Implement GSAP Animations in Next.js
- [ ] Create a Modal using Shadcn UI
- [ ] Build a Responsive Drawer using Shadcn UI
- [ ] Create an Image Carousel
- [ ] Build a Vertical Sidebar Navigation
- [ ] Implement Toast Notifications with Sonner
- [ ] Add Dark Mode and Light Mode
- [ ] Create Tables using a UI Component Library

### 🏗️ Phase 8: Full-Stack Project

- [ ] Start a Full-Stack Job Portal Application
- [ ] Plan the Project Structure and Features
- [ ] Build the Frontend UI
- [ ] Implement Routing and Layouts
- [ ] Connect the Database
- [ ] Implement CRUD Operations
- [ ] Add Form Validation and Error Handling
- [ ] Test the Application
- [ ] Deploy the Project
